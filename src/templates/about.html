About TVMaze-Sync

Automated TV show discovery and Sonarr integration

Overview

TVMaze-Sync is an automated TV show discovery service that bridges the TVMaze API and Sonarr. It continuously monitors TVMaze for new and updated TV shows, applies configurable filters, and automatically adds matching shows to your Sonarr library.

Key Features

  • Automatic discovery of new TV shows from TVMaze
  • Sophisticated multi-stage filtering (genre, language, country, rating, etc.)
  • Automatic addition of matching shows to Sonarr
  • Local SQLite cache for efficient filtering (~70k shows)
  • Prometheus metrics for monitoring
  • REST API for programmatic control
  • Web UI for easy management

Quick Start

1. Create Configuration

Create a config.yaml file:

tvmaze:
  rate_limit: 20  # requests per 10 seconds
  update_window: week

sync:
  poll_interval: 6h
  retry_delay: 1w
  abandon_after: 1y

exclude:
  genres:
    - Animation
    - Anime
  types:
    - Talk Show
    - News

selections:
  - languages: [English]
    countries: [US, GB]
    premiered:
      after: "2020-01-01"

sonarr:
  url: http://sonarr:8989
  api_key: ${SONARR_API_KEY}
  root_folder: /tv
  quality_profile: HD-1080p
  monitor: all
  search_on_add: true

storage:
  path: /data

server:
  enabled: true
  port: 5000
  api_key: ${SERVER_API_KEY}

logging:
  level: INFO
  format: json

2. Run with Docker

docker run -d \
  --name tvmaze-sync \
  -v ./config.yaml:/config/config.yaml:ro \
  -v tvmaze-data:/data \
  -e SONARR_API_KEY=your-sonarr-key \
  -e SERVER_API_KEY=your-server-key \
  -p 5000:5000 \
  ghcr.io/andronics/tvmaze-sync:latest

3. Using Docker Compose

version: '3.8'

services:
  tvmaze-sync:
    image: ghcr.io/andronics/tvmaze-sync:latest
    container_name: tvmaze-sync
    restart: unless-stopped
    volumes:
      - ./config.yaml:/config/config.yaml:ro
      - tvmaze-data:/data
    environment:
      - SONARR_API_KEY=${SONARR_API_KEY}
      - SERVER_API_KEY=${SERVER_API_KEY}
    ports:
      - "5000:5000"
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:5000/health"]
      interval: 30s
      timeout: 10s
      retries: 3

volumes:
  tvmaze-data:

Configuration Reference

Section Key Description
tvmaze rate_limit Requests per 10 seconds (default: 20)
update_window Update check window: day, week, month
sync poll_interval Time between sync cycles (e.g., 6h, 1d)
retry_delay Delay before retrying pending shows
abandon_after Time after which to abandon pending shows
exclude genres, types, languages, countries, networks Global exclusion filters (OR logic)
selections languages, countries, types, genres, status, premiered, rating, runtime Inclusion criteria (AND within, OR across)
sonarr url, api_key Sonarr connection settings
root_folder, quality_profile Default settings for added shows
server enabled, port, api_key HTTP server configuration

How It Works

Sync Process

  1. Initial Sync: On first run, fetches all shows from TVMaze (~70k shows across ~280 pages)
  2. Incremental Sync: Subsequent runs only fetch updated shows since last check
  3. Filtering: Each show is evaluated against global excludes, then selection criteria
  4. Sonarr Integration: Matching shows are added to Sonarr via API
  5. Retry Queue: Shows without TVDB IDs are queued for later retry

Filter Logic

Two-Stage Filtering:

  1. Global Excludes (OR): If show matches ANY exclude criterion, it's rejected
  2. Selections (AND within, OR across): Show must match ALL criteria within at least ONE selection

Troubleshooting

Shows not being added

Check the filter reasons in the Shows browser. Shows may be filtered due to global excludes or not matching any selection criteria.

Pending TVDB shows

Some shows don't have TVDB IDs on TVMaze. These are queued for retry. The TVDB ID is required for Sonarr integration.

Rate limiting errors

The TVMaze API has rate limits (20 requests/10s for free tier). The application handles this automatically with backoff/retry.

Sonarr connection issues

Verify the Sonarr URL and API key in your configuration. Check the /ready endpoint to see Sonarr connectivity status.
