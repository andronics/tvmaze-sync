API Documentation

REST API endpoints for programmatic access to TVMaze-Sync

Authentication

Protected endpoints require an API key. You can provide it in one of two ways:

  • Header: X-API-Key: your-api-key
  • Query Parameter: ?api_key=your-api-key

Public Endpoints

These endpoints do not require authentication.

GET /health

Liveness probe. Returns immediately to indicate the service is running.

Response

{"status": "healthy"}
GET /ready

Readiness probe. Checks database and Sonarr connectivity.

Response (200 OK / 503 Service Unavailable)

{
  "status": "ready",
  "database": true,
  "sonarr": true
}
GET /metrics

Prometheus metrics endpoint. Returns metrics in Prometheus exposition format.

Response (text/plain)

# HELP tvmaze_sync_shows_total Total shows in database
# TYPE tvmaze_sync_shows_total gauge
tvmaze_sync_shows_total{status="added"} 1203
tvmaze_sync_shows_total{status="filtered"} 67102
...

Protected Endpoints

These endpoints require authentication via API key.

POST /trigger

Manually trigger a sync cycle.

Success Response (200 OK)

{"status": "triggered"}

Error Response (409 Conflict)

{
  "status": "already_running",
  "error": "Already running - sync cycle in progress"
}
GET /state

Get current operational state and statistics.

Response

{
  "last_full_sync": "2024-01-15T10:30:00+00:00",
  "last_incremental_sync": "2024-01-15T12:00:00+00:00",
  "last_tvmaze_page": 280,
  "highest_tvmaze_id": 70123,
  "next_scheduled_run": "2024-01-15T18:00:00+00:00",
  "sync_running": false,
  "status_counts": {
    "added": 1203,
    "filtered": 67102,
    "pending_tvdb": 1818
  },
  "total_shows": 70123
}
GET /shows

Query shows from the database.

Query Parameters

Parameter Type Description
status string Filter by processing status (required)
limit integer Max results (default: 100, max: 1000)
offset integer Pagination offset (default: 0)

Example: GET /shows?status=added&limit=10

[
  {
    "tvmaze_id": 1,
    "tvdb_id": 81189,
    "title": "Under the Dome",
    "language": "English",
    "country": "US",
    "type": "Scripted",
    "status": "Ended",
    "processing_status": "added",
    ...
  }
]
POST /refilter

Force re-evaluation of all filtered shows against current selection criteria.

Response

{
  "status": "complete",
  "refiltered": 67102
}
GET /config

Get the complete running configuration.

Warning: This endpoint returns sensitive values like API keys. Use with caution.

Response (truncated)

{
  "tvmaze": { ... },
  "sync": { ... },
  "exclude": { ... },
  "selections": [ ... ],
  "sonarr": { ... },
  "storage": { ... },
  "logging": { ... },
  "server": { ... },
  "dry_run": false
}

Processing Status Values

Status Description
added Show was added to Sonarr
filtered Show was excluded by filter rules
pending_tvdb Show is waiting for TVDB ID (will retry)
pending Show is pending processing
exists Show already exists in Sonarr
failed Show processing failed permanently
abandoned Show was abandoned after timeout

Error Responses

401 Unauthorized

{"error": "Unauthorized"}

500 Internal Server Error

{
  "status": "error",
  "error": "Error description"
}
